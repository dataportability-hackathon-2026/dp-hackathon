# Data Portability Context

- [Data Transfer Initiative](https://dtinit.org/) — co-host; their open-source tools power Google, Meta, and Apple data transfers
- [DTI Portability Map](https://dtinit.org/portability-map) — comprehensive resource on data portability across platforms
- [Data Transfer Project (open source)](https://github.com/dtinit/data-transfer-project) — the actual framework; good starting point for Track 1
- [GDPR Article 20 — Right to Data Portability](https://gdpr-info.eu/art-20-gdpr/) — legal foundation for data portability rights
- [Google Data Portability API](https://developers.google.com/data-portability) — developer reference for portability integrations
