# Synthetic Data Generation

- [NVIDIA NeMo Synthetic Data Guide](https://docs.nvidia.com/nemo/microservices/latest/design-synthetic-data-from-scratch-or-seeds/index.html) — referenced by the DTI community as an effective approach for creating user memory datasets
- [PersonaHub (HuggingFace)](https://huggingface.co/datasets/proj-persona/PersonaHub) — 1 billion synthetic personas for data generation
- [Google Synthetic-Persona-Chat](https://huggingface.co/datasets/google/Synthetic-Persona-Chat) — 20k persona-based conversations
