# Oracle America, Inc. v. Google LLC

**Citation:** 593 U.S. 1 (2021)
**Year:** 2021
**Court:** Supreme Court of the United States
**Topic Area:** Intellectual Property / Technology

## Facts
Google copied approximately 11,500 lines of code from the Java SE application programming interface (API) developed by Sun Microsystems, later acquired by Oracle. Google used these declaring code lines and their structure in its Android operating system to allow programmers familiar with Java to write programs for Android. Oracle sued for copyright infringement, seeking billions in damages.

## Issue
Whether Google's copying of the Java SE API, including the declaring code and the structure of the API, constituted fair use under copyright law.

## Holding
The Court held 6-2 that Google's copying of the Java API was fair use. Justice Breyer's opinion analyzed all four fair use factors and found they favored Google. The Court emphasized that Google copied only what was needed to allow programmers to use their existing skills, that the API declarations were primarily functional, and that allowing Oracle to enforce its copyright would harm the public by locking in a platform and stifling the creativity that copyright seeks to promote.

## Significance
This decision resolved a decade-long dispute central to the software industry. It provided critical guidance on the copyrightability and fair use of software interfaces, clarifying that functional elements of APIs receive thinner copyright protection. The ruling was seen as a victory for software interoperability and innovation, though it left open the broader question of whether APIs are copyrightable in the first place.

## Key Quotes
> "Google's purpose was to create a different task-related system for a different computing environment (smartphones) and to create a platform — the Android platform — that would help achieve and popularize that objective."
